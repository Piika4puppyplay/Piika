# PuppyPhone 🐾📱

Lanceur Android (écran d'accueil) puppyplay néon, style Windows Vista Aero × Android 4.x — remplace Nova.

- Icônes 3D brillantes dessinées + logos d'origine « sous verre »
- Widgets d'époque : horloge flip, batterie, contrôle Wi-Fi / Bluetooth / 4G / lampe / son du fond
- Fond d'écran : néon animé, fond du téléphone, image, ou **vidéo MP4 avec le son** (le son continue écran éteint)
- **PupSon** : appli dans l'appli pour couper / remettre le son (aussi en notification et en tuile rapide)
- **Flair** : tri automatique hors ligne des applis installées dans des dossiers flottants (« À trier » en cas de doute), qui apprend de tes corrections
- Raccourcis : applis, raccourcis d'applis, liens web, épinglage depuis les autres applis

L'APK est construit automatiquement par GitHub Actions à chaque envoi sur la branche `puppyphone`
(onglet *Releases* → `PuppyPhone.apk`).
