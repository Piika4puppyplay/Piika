# PupDown 🐾 (version Android)

Branche dédiée à l'appli **PupDown** : comptes à rebours de festivals, tirelire, radio, table de mixage, Pup Pad et Pup Arcade.

L'APK est construit automatiquement par GitHub Actions à chaque mise à jour de cette branche.
Il se télécharge depuis l'onglet **Releases** du dépôt (versions « PupDown v1.0.x »).

- `app/src/main/assets/www/` : l'appli (HTML + voix + moteur 3D)
- `app/src/main/java/.../MainActivity.java` : la coque Android (WebView)
